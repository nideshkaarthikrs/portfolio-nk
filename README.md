# Nidesh Kaarthik — portfolio

Personal portfolio site. Built in phases per `PORTFOLIO_SPEC.md`.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Bricolage Grotesque (display) + Geist / Geist Mono (body, code) via `next/font`

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content model

Project data lives in [`lib/projects.ts`](lib/projects.ts). Case studies (from Phase 3 onward)
live as MDX in `content/work/`.
